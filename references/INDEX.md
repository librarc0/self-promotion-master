## 🎯 四种使用模式入口

### 模式 0：引导收集
```bash
# 适合需求还没想清楚：
# “开启引导模式，先问我问题，确认需求后再生成”
# skill 会分轮确认：产物、场合、受众、长度、素材、强度、事实边界
```

### 模式 A：白纸生成
```bash
# 告诉 skill：
# 【场景】+【场合】+【时长】+【核心素材】+【强度】
```

### 模式 B：草稿润色
```bash
# 直接粘贴你的草稿 + 【目标场景】+【场合】+【强度】
```

### 模式 C：素材提炼
```bash
# 直接粘贴你的零散素材（聊天记录/周报/邮件）+【场景】+【场合】
```

## ⚙️ 强度档位速记

| 档位 | 一句话 |
|---|---|
| 🟢 保守 | 数字说话 + 升维，措辞克制 |
| 🟡 标准 | 动词升级 + 故事 + 价值闭环（默认） |
| 🔴 激进 | 拔高格局 + 敢下判断 + 留白 |

## 💡 5 大武器速记

1. **动词升级** — 做了→主导
2. **数据锚定** — 必带数字
3. **维度拔高** — 个人→团队→公司→行业
4. **故事包装** — 背景冲突+转折+升华
5. **价值闭环** — 输入→动作→输出→影响→沉淀

## 📤 输出格式

引导模式先输出“需求确认摘要”，用户确认后再生成最终稿。

完整稿件输出三件套：
1. **润色后文本**
2. **关键改动说明**（表格）
3. **评委追问预案**（3 个 Q&A）

短句/单段润色输出轻量结构：
1. **改写版本**
2. **改动理由**
3. **风险提示**
