# 🤝 自我介绍模板

> 适用：群面、社交破冰、面试开场、会议开场、校友会

## 30 秒版（群面/快速破冰）

### 私企
> "大家好，我叫 XX，**目前在 [公司] 担任 [岗位]，专注 [方向] X 年**。
> 最近在做的一件事是 [项目一句话]，**目前已经 [一个数据亮点]**。
> 平时爱好 [X]，希望能和在座各位多交流。"

### 国央企
> "大家好，我叫 XX，**来自 [单位] [部门]，主要从事 [方向] 工作**。
> **立足本职、主动担当**，**在 [一个亮点] 方面取得了一定成效**。
> 很高兴认识大家。"

### 外企
> "Hi, I'm [Name]. I work as [Role] at [Company], focusing on [Domain].
> Most recently I [one accomplishment with number]. Looking forward to connecting with you all."

### 学校
> "大家好，我叫 XX，**师从 XXX 教授，研究方向是 [XX]**。
> 最近在做 [研究/项目一句话]，**目前在 [一个亮点] 方面有一些阶段性成果**。
> 请多指教。"

## 1 分钟版（面试 / 会议开场）

```
【第 1 句 · 名字 + 身份 + 一句核心定位】
大家好，我叫 XX，**目前在 [单位] 担任 [岗位]，核心方向是 [X]**。

【第 2-3 句 · 核心成果（2 个数字）】
过去 X 年，**我聚焦 [方向]，**主导了 X 个项目，**实现了 [数据 1]，
节约/创造了 [数据 2]**。

【第 4 句 · 差异化优势】
我比较擅长 [X 能力]，**曾用 [方法] 解决过 [具体场景]**。

【第 5 句 · 价值匹配 / 为什么在这里】
今天来 [这个场合]，**希望能在 [方向] 上和各位多交流**，
也期待未来有机会和 [受众] 合作。
```

## 3 分钟版（深入介绍 / 校友聚会 / 答辩开场）

```
【第 1 段 · 30 秒 · 我是谁】
- 名字、单位、岗位
- **一句话核心定位**（"我是做 X 的人"）

【第 2 段 · 1 分钟 · 我做过什么（2-3 个亮点）】
- **亮点 1**：[数字] + 一句话
- **亮点 2**：[数字] + 一句话
- **亮点 3**（可选）：[数字] + 一句话

【第 3 段 · 1 分钟 · 我擅长什么 / 我的方法论】
- **核心方法论 1**：……
- **核心方法论 2**：……

【第 4 段 · 30 秒 · 我现在在做什么 / 未来做什么】
- **当前在做的项目**：……
- **未来的方向**：……

【第 5 段 · 30 秒 · 我想找什么样的人 / 合作意向】
- 寻求合作：……
- 期待交流：……
```

## 群面特别版（30 秒 · 抢答 / 第一个发言）

> "我叫 XX，**我的核心定位是 X**。
> **在 X 方面，我主导过 [一个有冲击力的成果]**。
> **今天我想从 [X 角度] 来切入这个讨论**。"

## 不同场合的开场白适配

| 场合 | 开场白建议 |
|---|---|
| **群面** | 先手发言 = 加分项。先用模板抢下一轮陈述。 |
| **校友会** | 加入学校元素（"作为 X 校友……"），拉近情感距离。 |
| **学术会议** | 加师承、加研究方向、加代表论文。 |
| **相亲/社交** | 突出"有趣的人设"而非"成就"，但要带一个让人记住的钩子。 |
| **公司年会** | 加一句公司梗/年度梗/老板梗，但要克制。 |
| **视频会议（外企）** | 1 分钟内，强调"deliverable + impact + role"。 |

## 反例（不要这样自我介绍）

| 反例 | 为什么错 |
|---|---|
| "我性格开朗、勤奋好学、乐于助人……" | 形容词堆砌，假大空 |
| "我毕业于 985，GPA 3.9，ACCA 12 门通过……" | 简历堆砌，没故事没观点 |
| "我做过很多项目……（列举 10 个）" | 没重点，没记忆点 |
| "我是一个普通但努力的人" | 自我矮化，零竞争力 |
| "我主要是负责 X 这块工作的" | 太老实，浪费自我展示机会 |

## 加分小技巧

1. **加一个"金句"**：让评委/听众记住你的一句话钩子。
2. **加一个"反差"**：例如"我是学法律的，但我做了 5 年数据产品"——记忆点。
3. **加一个"具体场景"**：比"我擅长沟通"更有效的是"我曾在 24 小时内协调 3 个部门解决了 X 危机"。
4. **加一个"数字"**：30 秒内放 1-2 个数字，胜过 10 个形容词。
5. **加一个"金句结尾"**：让结尾比开头更亮。
