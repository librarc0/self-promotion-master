# 🚀 晋升答辩 / 述职竞聘模板

> 适用：年度晋升答辩、竞聘上岗、转正答辩、述职汇报

## 通用结构（私企版，8 分钟）

> 各场合的差异请参考对应 tones 文件。

```
【第 1 段 · 30 秒 · 自我介绍 + 定位】
我是 XX，XXXX 年加入公司，目前在 XX 部门担任 XX。
过去 X 年，我聚焦 XX 方向，**作为 X 角色，**驱动了 X 个关键项目落地。
今天汇报的主题是：XXXX。

【第 2 段 · 1 分钟 · 岗位认知 / 为什么是我】
对 [目标岗位] 的理解，我认为是三个关键词：X、X、X。
- X：……
- X：……
- X：……

我的核心优势可以总结为三句话：
1. X（最匹配目标岗位的能力）
2. X（差异化能力）
3. X（未来潜力）

【第 3 段 · 4-5 分钟 · 核心业绩（最重要）】
分 2-3 个核心成果，每个用 STAR 框架：

【成果 1：XXX 项目的从 0 到 1 搭建】
- 背景：当时面临 X 挑战 / 行业内 Y 普遍认为不可能
- 我的角色：作为 X，主导了 X
- 关键动作：……
- 量化结果：实现 X% 提升 / 节约 X 万成本 / 提前 X 周交付
- 价值升维：覆盖 X 场景 / 沉淀为 X 方法论 / 跨 X 团队复用

【成果 2：……】
（同上结构）

【成果 3：……】
（选讲，可不展开）

【第 4 段 · 1 分钟 · 能力沉淀 / 复盘思考】
经过这 X 年的积累，我形成了 3 个核心能力：
- X 能力：……（用具体案例佐证）
- X 能力：……（用具体案例佐证）
- X 能力：……（用具体案例佐证）

【第 5 段 · 1 分钟 · 反思 + 未来规划】
做得不够好的地方：……
（必须有自我反思，展示客观和成长性）

下一步规划：……（针对目标岗位设计）

【第 6 段 · 30 秒 · 收尾】
以上就是我的汇报。**晋升到 [目标岗位] 后，我将在 X 方向持续投入，**
**为团队 / 部门 / 公司创造 X 价值**。
恳请各位评委批评指正，谢谢！
```

## 不同场合的"开场 30 秒"差异

### 私企
> "我是 XX，过去 X 年我作为 XX 角色的核心 owner，主导了 X 个关键项目落地。
> **我最自豪的，是用 X 的方法做出了 Y 的成果**。"

### 国央企
> "根据……部署，结合岗位职责，现将本人近年来的工作履职情况汇报如下。
> **本人始终把……放在首位，**在 X 方面取得了一定成效。"

### 外企
> "Hi everyone, I'm [Name]. Over the past X years, I've **owned** X critical initiatives, 
> **delivered** Y measurable impact, and **built** Z scalable capabilities.
> **Today I'd like to share 3 key accomplishments** that demonstrate my readiness for [next level]."

### 学校
> "各位评委好。我是 XX，导师是 XXX 教授。
> 我的研究方向是 XX，**核心工作围绕 X 问题展开**，**形成了 X 研究框架**。
> **本次答辩主要汇报 X 个研究工作**。"

## 三个强度档的差异

| 档位 | 适合场景 | 措辞风格 |
|---|---|---|
| 🟢 保守 | 央企/外企/正式答辩 | "主导 / 参与 / 负责 / 取得一定成效" |
| 🟡 标准 | 私企晋升/日常述职 | "操盘 / 攻坚 / 推动 / 沉淀方法论" |
| 🔴 激进 | 群面/抢答/校友会 | "战略级 / 行业首创 / 重新定义 / 标志性成果" |

## 评委最常问的 10 个问题（提前准备）

1. **"你说的"主导"具体是什么角色？团队多大？你是负责人还是参与者？"**
2. **"X 那个项目的最终业务结果是什么？有没有后续数据？"**
3. **"如果让你重新做一次，你会怎么改进？"**
4. **"你做的这件事，换个人做能不能做出来？你的不可替代性在哪？"**
5. **"你的成长性体现在哪？晋升后能承担什么新职责？"**
6. **"你提到的 X 数字，是怎么算出来的？"**
7. **"和外部/竞品比，你的水平在哪？"**
8. **"在做的过程中，遇到的最大困难是什么？你是怎么解决的？"**
9. **"这件事是公司战略级的，还是你自己想做的？"**
10. **"你怎么看 [目标岗位] 的工作？你认为自己最缺的是什么？"**

## 一句话杀伤力结尾（私企 · 激进版）

> "**我做增长不是 0 优化 0.1，我是构建飞轮。**
> **如果给我 [目标岗位] 这个平台，**
> **我会用 X 时间，把 X 业务从 1 做到 10。**"

## 一句话杀伤力结尾（国央企 · 标准版）

> "**成绩属于过去，奋斗赢得未来。**
> **下一步，我将继续在 X 方向深耕细作，**
> **以实际行动践行 X 担当，为公司高质量发展贡献自己的力量。**"
