# 📝 年度述职 / 工作汇报模板

> 适用：年终/半年/季度述职、项目复盘、给老板的工作汇报

## 通用结构（10 分钟版 · 私企）

```
【第 1 段 · 1 分钟 · 概述 + 关键数据】
各位领导/老板好，**现将本人 X 年（季度）的工作情况汇报如下**。
过去这一年，**我作为 X 角色，**主导/参与了 X 个关键项目，**实现了：
- 业绩数据 1（量化）
- 业绩数据 2（量化）
- 业绩数据 3（量化）**

【第 2 段 · 5 分钟 · 核心业绩（3-5 个亮点）】

按重要性排序，每个亮点使用 "CAR" 结构：
- **Challenge（挑战）**：当时面临 X 挑战
- **Action（我的动作）**：我主导了 X，核心做了 ABC
- **Result（量化结果）**：实现了 X 数据 / X 提升 / X 节约

【亮点 1：X 项目的从 0 到 1】（最重要 / 数据最硬）
……

【亮点 2：X 流程的优化 / 提效】
……

【亮点 3：X 团队建设 / 跨部门推动】
……

【第 3 段 · 1 分钟 · 能力沉淀 / 方法论】
经过这一年，**我沉淀了 X 套可复用的方法论 / SOP**，
**为团队/部门留下了 X 项可继承的资产**：
- 资产 1：……
- 资产 2：……

【第 4 段 · 1 分钟 · 反思与不足】
复盘下来，**我意识到自身在以下方面仍有提升空间**：
- 不足 1：……（要真诚，不要避重就轻）
- 不足 2：……
- 反思：……

【第 5 段 · 1 分钟 · 下一步规划】
基于公司 X 战略 + 部门 X 目标，**我的下一阶段规划如下**：
- 短期（Q1）：X
- 中期（半年）：X
- 长期（全年）：X

【第 6 段 · 1 分钟 · 收尾】
**成绩的取得，离不开 [上级] 的指导和 [团队] 的支持。**
**下一步，我将继续在 X 方向深耕，**为 [团队/部门/公司] 创造 X 价值。
**恳请各位领导批评指正。**
```

## 国央企版结构

```
【开场】
"根据……部署，现将本人 X 年履职情况汇报如下。"

【主体 - 五个方面】
1. **政治建设方面**：深入学习……，自觉在思想上政治上行动上同……保持高度一致
2. **履职尽责方面**：（核心业务成果，3-5 个亮点）
3. **廉洁自律方面**：严格落实中央八项规定精神，坚决守住底线
4. **存在的不足**：（真诚反思）
5. **下一步打算**：（分 3 个时间维度）

【收尾】
"以上汇报，不当之处敬请批评指正。"
```

## 外企版结构

```
【开场 · 30 秒】
"Over the past [X months/quarter], I owned [X scope].
Key deliverables: [1-2 lines summary with metrics]."

【主体 · 5 段 · 5 个 KPI/项目】
每个项目用 "Context → Action → Result" 3 句话讲完。
每个项目配 1-2 个 metric。

【结尾】
"Looking forward, my focus areas are X, Y, Z,
aligned with the team's [roadmap/OKR]."
```

## 述职常见雷区

| 雷区 | 怎么改 |
|---|---|
| 流水账（"周一做了 X，周二做了 Y"） | 按重要性/价值排序，按主题分类 |
| 没数字 | **每个亮点必须有 1 个数字** |
| 太谦虚 | 把"参与"改成"作为核心 owner 主导" |
| 全是成绩，没反思 | 必备 1 段真诚反思（建议 1 短 1 长） |
| 没价值升维 | 必加一段"我的工作对部门/公司有什么价值" |
| 自我感动 | 删除所有"加班/熬夜/辛苦"等字眼 |
| 没下步规划 | **结尾必须给老板一个"你接下来要做什么"** |

## 述职中"价值升维"的三个层次

```
第 1 层（最低）：我做了 X 工作
第 2 层（标准）：我做的 X 工作，**为团队/部门解决了 Y 问题**
第 3 层（高手）：我做的 X 工作，**对部门/公司的 X 战略形成了支撑**
```

> **述职是"老板给你打分"的场合。老板不关心你多努力，关心你创造了什么价值。**

## 数据话术清单

不会算精确数字时，用这些"模糊但有冲击力"的表达：

- 业绩类："超额完成 X%" / "Top X%" / "超额 X 个百分点"
- 效率类："**提效 X%**" / "从 X 缩短到 Y" / "节约 X 人天"
- 规模类："覆盖 X 业务线" / "赋能 X 人" / "影响 X 万用户"
- 质量类："X 事故 / 0 故障 / 0 投诉"
- 沉淀类："形成 X 套 SOP" / "沉淀 X 项组织资产"

## 述职前必问自己的 5 个问题

1. **我今年最重要的 3 件事是什么？**（用 1 句话说清）
2. **每件事的数据/成果是什么？**（必须量化）
3. **我做的这些事，对部门/公司有什么价值？**（升维）
4. **我沉淀了什么可复用的方法论/资产？**（证明不可替代性）
5. **我有什么不足？下一步怎么补？**（真诚 + 规划）

> 答不上来 = 述职注定平淡。
