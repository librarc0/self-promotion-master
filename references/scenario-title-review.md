# 职称评审材料模板

> 适用：初级、中级、高级、正高级职称评审的个人总结、业绩材料、答辩陈述、代表作说明、成果梳理。

## 核心原则

职称评审不是普通述职。它看重的是“任现职以来”的持续贡献、专业能力、成果证据和行业/单位认可。

写作顺序：
1. **资格匹配**：任职年限、学历、继续教育、岗位职责是否满足申报条件
2. **专业能力**：能否独立或牵头解决本专业问题
3. **业绩成果**：项目、课题、论文、专利、标准、奖项、转化、教学/服务成果
4. **证据闭环**：每个成果能否对应证明材料
5. **级别口径**：级别越高，越强调体系建设、行业影响、人才培养和方法创新

不要编造论文、专利、奖项、课题、项目金额、排名、作者顺序、完成人顺序。缺失时用 `[待补充：证明材料/排名/时间]`。

## 四个级别的评审重点

| 级别 | 核心问题 | 写作重点 | 避免 |
|---|---|---|---|
| 初级 | 是否具备岗位基本专业能力 | 学习成长、规范执行、独立完成基础任务 | 过度拔高成“行业影响” |
| 中级 | 是否能独立负责专业工作 | 独立承担项目、解决实际问题、形成稳定产出 | 只写参与，不写职责边界 |
| 高级 | 是否能牵头复杂工作并形成示范 | 牵头攻关、复杂问题解决、成果推广、团队带教 | 只有项目堆砌，没有方法和影响 |
| 正高级 | 是否有行业/区域/单位标杆性贡献 | 体系建设、原创性成果、行业标准、重大项目、人才梯队 | 把普通管理成果包装成战略级贡献 |

## 初级职称

### 评审关注
- 是否掌握本专业基础理论和工作规范
- 是否能在指导下或独立完成基础任务
- 是否有稳定的工作态度、学习能力和执行质量

### 表达结构
```
任现岗位以来，我围绕 [专业方向]，重点参与/承担了 [工作模块]。
在 [导师/团队/项目] 的指导下，逐步掌握了 [专业技能/流程规范]，
能够独立完成 [具体任务]，并在 [质量/效率/规范性] 方面取得改进。
```

### 可用素材
- 完成的基础项目、日常工作量、服务对象数量
- 培训、继续教育、证书、技能提升
- 被采纳的建议、小改小革、流程优化
- 质量记录：零差错、按期完成、满意度、检查通过

### 语气
克制、踏实、成长导向。少用“主导/开创”，多用“承担/参与/独立完成/逐步形成”。

## 中级职称

### 评审关注
- 是否能独立承担专业技术工作
- 是否能解决本岗位常见复杂问题
- 是否有可验证的项目成果、论文/报告/专利/标准化成果

### 表达结构
```
任现职以来，我聚焦 [专业方向]，独立承担/负责了 [项目或工作]。
面对 [问题/难点]，我通过 [方法/技术路线/管理措施]，
实现了 [结果数据]，形成了 [制度/报告/技术文档/论文/专利/经验做法]。
```

### 可用素材
- 独立负责的项目、课题、工程、产品、教学、医疗、管理模块
- 指标提升、成本节约、效率提升、质量改进、安全稳定
- 论文、专利、软著、标准、制度、调研报告
- 年度考核、获奖、表彰、客户/服务对象评价

### 语气
突出“独立性”和“稳定产出”。可以写“负责/牵头模块”，但不要把协作项目写成个人全权主导。

## 高级职称

### 评审关注
- 是否能牵头解决复杂、关键、跨部门或高难度问题
- 是否形成可推广的方法、制度、技术路线或团队能力
- 是否有较高质量代表作、重要项目、奖项、标准、专利、课题
- 是否承担带教、评审、指导、专业建设责任

### 表达结构
```
任现职以来，我围绕 [单位/行业重点方向]，牵头推进 [关键项目/技术攻关/体系建设]。
针对 [长期痛点/复杂问题]，构建了 [方法体系/技术路线/工作机制]，
推动 [成果] 在 [范围] 应用，取得 [数据/奖项/评价/推广情况]。
同时，我在 [人才培养/标准建设/专业指导] 方面持续投入，带动团队专业能力提升。
```

### 可用素材
- 牵头重大项目、关键技术攻关、重点工程、重点课题
- 成果推广应用范围：单位内、多部门、区域、行业会议
- 代表作：高质量论文、专利、标准、指南、教材、课题、奖项
- 人才培养：带教人数、骨干培养、培训授课、评审专家经历
- 专业影响：会议报告、专家库、标准制定、成果转化

### 语气
突出“牵头、复杂性、示范性、推广价值”。必须让每个拔高判断都有证据支撑。

## 正高级职称

### 评审关注
- 是否在本专业领域形成高水平、系统性、标志性成果
- 是否对行业、区域、学科、单位专业体系有显著贡献
- 是否具备专业引领、标准制定、人才梯队建设、重大项目组织能力
- 是否有高等级奖项、重大课题、核心代表作、行业认可

### 表达结构
```
任现职以来，我立足 [专业领域/行业方向]，持续围绕 [核心问题] 开展系统性工作。
在 [重大项目/关键技术/学科建设/标准体系] 中，我作为 [角色]，
形成了 [原创性成果/体系化方法/标志性成果]，
推动 [单位/区域/行业] 在 [领域] 实现 [影响]。
同时，通过 [人才培养/平台建设/标准制定/学术共同体建设]，
持续提升本专业方向的整体发展水平。
```

### 可用素材
- 国家/省部/行业级项目、课题、奖项、平台、标准
- 第一作者/通讯作者论文、核心代表作、专著、教材、指南
- 发明专利、成果转化、重大工程应用、行业示范
- 专家委员会、学会任职、评审专家、标准/指南制定
- 梯队建设：培养高级人才、研究团队、专业平台

### 语气
强调“系统性、原创性、引领性、标志性”。正高级可以升维到行业/学科/区域影响，但必须绑定真实证据。

## 引导收集专用问题

职称评审进入引导模式时，除通用问题外必须追问：

1. 申报级别：初级 / 中级 / 高级 / 正高级
2. 申报系列/专业：工程 / 教师 / 卫生 / 经济 / 会计 / 农业 / 新闻 / 档案 / 其他
3. 任现职时间、现岗位、申报地区或单位要求
4. 已有证明材料：论文、专利、项目、课题、奖项、标准、考核、继续教育、培训、聘书
5. 代表性成果 3-5 项：每项写清角色、排名、时间、证明材料
6. 是否需要生成：个人专业技术工作总结 / 业绩成果材料 / 答辩陈述 / 代表作说明 / 材料目录

## 输出类型

### 个人专业技术工作总结

结构：
1. 基本情况与任职经历
2. 思想政治与职业操守（国央企/事业单位/学校场景尤其重要）
3. 专业技术能力提升
4. 主要业绩成果（按代表性成果排序）
5. 科研/论文/专利/标准/成果转化
6. 人才培养与团队贡献（高级及以上必须强化）
7. 不足与下一步计划

### 业绩成果材料

每项成果用这个结构：
```
【成果名称】
时间：
本人角色：
难点：
关键动作：
成果数据：
证明材料：
对应评审能力：
```

### 答辩陈述

结构：
1. 30 秒基本情况
2. 1 分钟申报资格与专业定位
3. 3-5 分钟代表性成果
4. 1 分钟专业贡献与推广价值
5. 30 秒不足与未来规划

## 常见雷区

| 雷区 | 改法 |
|---|---|
| 只罗列工作，没有对应评审条件 | 每项成果标注“对应评审能力” |
| 把所有项目都写成主导 | 按真实角色写“主持/负责/参与/协同/排名第 X” |
| 初级写得像正高级 | 按级别控制升维高度 |
| 高级/正高级只写个人执行 | 必须补“推广、带教、体系、行业影响” |
| 论文、专利、奖项信息不完整 | 用占位符提示补齐作者顺序、授权号、获奖等级、时间 |
