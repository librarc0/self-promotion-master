# 🎯 其他场景速查

## 💼 求职面试自我介绍

### 30 秒版（HR 初面）
> "您好，我叫 XX，**X 年 X 方向经验，**目前在 [公司] 担任 [岗位]。
> **核心成果：**[一句话 + 1-2 个数据]。
> **核心能力：**[X 能力 1] + [X 能力 2]。
> **求职意向：**[目标岗位] / [目标方向]。"

### 3 分钟版（业务面）
```
1. 名字 + 学历 + 核心方向（30 秒）
2. 过去 X 年我的核心成长路径（30 秒）
3. 最有代表性的 2-3 个项目（1.5 分钟，用 STAR）
4. 我的核心方法论 / 差异化能力（30 秒）
5. 为什么选贵司 / 为什么选这个岗位（30 秒）
```

### 行为面试万能公式（STAR-L）
- **S**ituation：背景
- **T**ask：目标 / 你的职责
- **A**ction：具体做了什么
- **R**esult：量化结果
- **L**earning：你的学习 / 反思（**加分项**，展示成长性）

## 🎓 答辩 / 开题

### 论文答辩开场（5 分钟）
```
1. 研究背景与问题（1 分钟）
2. 文献综述与研究空白（1 分钟）
3. 研究框架与方法（1.5 分钟）
4. 核心发现与创新点（1 分钟）
5. 不足与展望（30 秒）
```

### 开题报告
```
1. 选题背景与意义（含现实关怀）
2. 国内外研究现状
3. 研究内容与拟创新点
4. 研究方法与技术路线
5. 进度安排与预期成果
```

### 答辩收尾金句
- "**本文的工作，**为 XX 领域提供了一个新的分析视角，**为后续研究奠定了基础**。"
- "**研究的价值不仅在于结论本身，**更在于研究过程中形成的……方法论。"
- "**展望未来，**我将继续在……方向深耕，**为推动 XX 学科的发展贡献绵薄之力**。"

## 🗣️ 即兴发言 / 抢答 / 总结陈词

### 抢答开场（30 秒内建立权威）
> "**我先说一个判断：X。**理由有三点：……"

### 圆桌发言三段式
```
1. 我同意 X 老师/同学的 XX 观点（拉同盟）
2. 我想从 XX 角度做一个补充（差异化）
3. 我有一个具体案例可以佐证（故事化）
```

### 总结陈词（必备句式）
> "**刚才各位嘉宾/同事的分享，**让我对 X 有了更深的理解。
> **我的核心收获是三点**：……
> **我认为接下来的关键，**在于 X、Y、Z。
> **最后，**再次感谢 [主办方/主持人] 的组织。"

## 🥂 社交破冰 / 校友会 / 相亲

### 校友会版（3 分钟）
```
1. "我是 X 级 X 专业的 X"（身份 + 情感纽带）
2. "目前在 X 行业做 X"（职业定位）
3. "我最近在做 X，有兴趣的校友可以多交流"（开放钩子）
4. "看到这么多校友特别亲切，期待和大家多链接"（情感收尾）
```

### 校友会高端版（突出"可链接性"）
> "我现在在 [公司] 负责 [方向]，**手上对接的资源和校友们可能有些交集**。
> **如果大家在 X 方向有需求，随时找我**，这杯咖啡我请了。"

### 相亲 / 朋友聚会版（人设 > 成就）
- 不要列简历。
- 加一个"人设标签"：例如"做金融的产品经理 / 半职业咖啡爱好者 / 一周读一本书的强迫症患者"。
- 加一个"反差钩子"：例如"我虽然是做金融的，但我曾经在 X 沙漠徒步 100 公里"。
- 加一个"邀约钩子"：例如"如果你也对 X 感兴趣，下次可以一起 X"。

## 📧 求职信 / Cold Email

### 求职信三段式
```
1. 我是谁 + 我为什么写这封信（50 字）
2. 我和这个岗位的 3 个匹配点（200 字）
3. 我能为团队带来的具体价值（100 字）
```

### Cold Email 模板（外企 BD / 求职）
```
Subject: [具体价值点] from [Name]

Hi [Name],

I'm reaching out because [具体原因 - 1 句话].
Currently I [我的核心定位 - 1 句话].
[具体的、与对方相关的成就 - 1 句话 + 数据].

Would you be open to a 15-min chat? Happy to work around your schedule.

Best,
[Name]
```

## 🚨 高风险场景特别提示

### 答辩被追问时
- ✅ 先复述问题（"您问的是不是……"），给自己 5 秒思考时间
- ✅ 不知道就老实说"这个数据我回去确认一下"（比硬编被拆穿好 100 倍）
- ✅ 把"我不知道"改成"**这个维度我目前的研究还没有覆盖到，**这是下一步要重点补充的方向"

### 群面抢答时
- ✅ 不要"我同意 X 然后再说一遍"
- ✅ 用"**我有一个不同的角度，**……"建立差异化
- ✅ 抢答要短（30 秒内），长答留给你被点名时

### 私下被问"你年薪多少"
- ✅ "**这个不太方便细说，**但比同龄同岗位的 P50 还是要好一些"（模糊带过）
- ✅ "**这两年成长挺快的，**翻了一番吧"（不报具体数）
- ❌ 不要直接报数（私企/外企忌讳）

### 校友会被问"你做得这么好，有啥诀窍"
- ✅ "**主要是跟对团队、做对方向，**自己运气不错"（谦虚 + 暗示有实力）
- ❌ "我也没啥，就是努力"（太假，校友里谁都比你懂）
- ❌ "我年薪 X 万"（自爆家底 = 拉仇恨）
