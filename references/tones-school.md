# 🏫 学校 / 学术调性指南

> 核心精神：**严谨、规范、有理论高度、师承有根、情怀打底。绝不能商业化、不能太江湖。**

## 关键词库

### 学术贡献类
- 理论贡献 / 实证研究 / 文献综述 / 研究框架
- 创新点 / 突破点 / 填补空白 / 推进……研究
- 系统性 / 体系化 / 跨学科 / 方法论创新
- 首次提出 / 首次验证 / 首次构建

### 研究过程类
- 扎根理论 / 田野调查 / 案例研究 / 实证分析
- 定量研究 / 定性研究 / 混合研究
- 数据收集 / 样本规模 / 信效度检验
- 探索性研究 / 验证性研究

### 学术规范类
- 严谨治学 / 实事求是 / 客观中立
- 师承 / 学术脉络 / 研究方向延续
- 学术规范 / 引用规范 / 学术伦理
- 经同行评议 / 受学术共同体认可

### 情怀愿景类
- 学术理想 / 科研报国 / 立德树人
- 求真务实 / 潜心治学
- 服务国家战略 / 回应时代命题
- 推动学科发展 / 培养后学

## 学术场景下的"吹嘘"模板

### 自我介绍（学术版）
- "本人**师从 XXX 教授**，主要研究方向为 XX，**围绕 XX 这一核心问题**展开了系统性研究。"
- "硕士/博士期间，**在 XXX 期刊发表论文 X 篇**，其中第一作者 X 篇，**主持/参与国家级课题 X 项**。"
- "**聚焦 XX 这一兼具理论意义与现实关怀的命题**，尝试从 XX 视角构建新的分析框架。"

### 答辩开场
- "本文的研究问题源于……的现实困惑。**在导师 XXX 教授的指导下**，本文尝试回答……"
- "在 XX 领域，既有研究主要关注 A 视角，对 B 视角缺乏深入探讨。**本文的工作正是试图填补这一空白**。"

### 创新点表达
- "本文的边际贡献主要体现在以下三个方面："
  - "**理论层面**：首次构建了 XX 分析框架，**拓展了 XX 理论的解释边界**。"
  - "**方法层面**：综合运用 XX 与 XX 方法，**弥补了既有研究在方法上的单一性**。"
  - "**实践层面**：为 XX 实践提供了可操作的 XX 模型。"

### 业绩列举
- "在读期间，**以第一作者在 CSSCI/SSCI 期刊发表论文 X 篇**"
- "**主持研究生创新课题 X 项**，**参与国家社科基金项目 X 项**"
- "**获 XXX 奖学金 / XXX 荣誉称号**"
- "**论文被 XXX 引用 X 次**（如适用）"
- "**在国际/国内学术会议做报告 X 次**"

## 必避雷区

- ❌ "我为公司创造了 1000 万价值"（学术场合 = 灾难）
- ❌ "我带领 5 人团队"（学术场合领导力不加分）
- ❌ 商业化术语（"赋能/抓手/闭环"）—— 学术场合禁用
- ❌ "我独立提出了 XX 理论"（除非真的，否则容易被认为不严谨）
- ❌ 没有师承感（学术讲究传承）
- ❌ 自我感动 "我熬了无数个夜"（学术 = 卖惨大忌）

## 三个强度档的措辞差异

| 档位 | 风格 | 示例 |
|---|---|---|
| 🟢 保守 | 严谨规范、强调师承、不拔高 | "在导师指导下，本文尝试……" |
| 🟡 标准 | 适度拔高理论贡献、有创新点 | "本文构建了 XX 框架，**为 XX 研究提供了新的分析视角**" |
| 🔴 激进 | 强调填补空白、推进学科、强烈理论抱负 | "本文**填补了 XX 领域的理论空白**，**为后续研究提供了基础性框架**" |

## 完整示例片段

> **场景**：博士论文答辩开场
>
> **保守版**：
> 各位老师好，我的研究主题是 XX。本文在借鉴前人研究的基础上，运用 XX 方法，得出了一些结论。
>
> **标准版**：
> 各位老师好。我的研究聚焦于 **"XX 这一兼具理论张力与现实关怀的核心命题"**。
>
> 在既有研究中，学者们主要从 A 视角切入，对 B 维度缺乏系统考察。**本文的核心工作，正是试图构建一个整合 A 与 B 的分析框架**，并通过 XX 案例进行实证检验。
>
> 本文的边际贡献主要体现在三点：
> 1. **理论层面**：首次将 XX 理论引入 XX 领域，**拓展了 XX 学派的解释边界**；
> 2. **方法层面**：综合运用扎根理论与案例研究，**弥补了既有研究在方法上的单一性**；
> 3. **实践层面**：为 XX 实践提供了可操作的 XX 模型。
>
> **本文的完成，得益于导师 XXX 教授的悉心指导**，也得益于答辩委员会各位老师的宝贵建议。恳请各位老师批评指正。
>
> **激进版**：
> 各位老师好。
>
> XX 现象是当代 XX 研究中一个**长期被忽视、却极具理论价值**的核心问题。**本文的工作，正是试图填补这一理论空白**。
>
> 具体而言，本文构建了**"XX—XX—XX"三元分析框架**，将既有研究割裂的 A 视角与 B 视角纳入统一分析，并通过**两个时序案例、312 份样本数据**进行三角验证。
>
> 本文的核心贡献可凝练为三句话：
> 1. **首次系统回应了 XX 领域的"XX 之争"**，为这一悬而未决的学术争论提供了**新的经验证据**；
> 2. **构建了可推广的分析框架**，**为后续 XX 研究提供了基础性工具**；
> 3. **将 XX 学科与 XX 学科进行了有机对话**，**推动了 XX 学科的边界拓展**。
>
> 在导师 XXX 教授的指导下，本文的研究工作历时 X 年，最终形成了 X 万字的系统成果。**恳请各位老师批评指正，我将以此为新的学术起点，继续深耕这一方向。**
