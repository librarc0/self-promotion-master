# 🏛️ 国央企调性指南

> 核心精神：**稳、大气、突出政治属性和集体主义；个人是螺丝钉，但要让自己这颗螺丝钉看起来最亮。**

## 关键词库

### 政治站位类（必带）
- 深入学习贯彻……精神 / 落实……战略部署
- 围绕中心、服务大局
- 心怀"国之大者" / 自觉站在……高度
- 立足新发展阶段，贯彻新发展理念，构建新发展格局
- 推动高质量发展
- 坚持和加强党的全面领导
- 党建引领业务深度融合

### 担当作为类
- 攻坚克难 / 啃硬骨头 / 敢于斗争 / 善于斗争
- 迎难而上 / 主动作为 / 善作善成
- 顶住压力 / 经受考验
- 关键时刻冲得上去 / 危难关头豁得出来

### 实绩成效类
- 提质增效 / 降本增效 / 减亏增盈
- 国有资产保值增值
- 圆满完成 / 超额完成 / 提前完成
- 零事故、零差错、零投诉
- 数量与质量并重、规模与效益齐升

### 集体荣誉类
- 在……的正确领导下 / 在……的关心指导下
- 与同事们一道 / 与团队共同
- 集体的力量 / 团队协作的结晶
- 得到上级肯定 / 受到……表彰
- 发挥了应有作用 / 作出了应有贡献

### 自律反思类
- 对照……要求 / 检视自身
- 刀刃向内 / 自我革命
- 履职尽责 / 忠诚干净担当
- 仍有不足 / 仍需努力 / 持续改进

## 万能句式（直接套用）

### 开场
- "根据……的统一部署，结合自身岗位职责，现将本人……情况汇报如下，不当之处敬请批评指正。"
- "一年来，在……的正确领导下，我始终把……放在首位……"

### 主体段
- "坚持把……作为第一要务，主动对标对表……"
- "在……的关键时期，我作为……，坚持……，圆满完成……"
- "聚焦……，聚力……，聚合……，推动……"
- "围绕中心工作，主动服务大局，做到……"

### 数字表达
- "较去年同期增长 X%"
- "节约资金 X 万元，超额完成 X%"
- "实现历史性突破 / 跨越式增长"
- "在公司系统内排名前 X"
- "获得 X 项荣誉 / X 项表彰"

### 收尾
- "成绩的取得，离不开……的正确领导，离不开同事们的支持配合。"
- "下一步，我将继续……以实际行动践行……"
- "恳请各位领导批评指正，我将以此次……为新起点……"

## 必避雷区

- ❌ "我带领团队"（→ 改"在团队共同努力下，我作为……"）
- ❌ "我主导了公司战略转型"（→ 改"参与/推动公司战略转型的具体落实工作"）
- ❌ "创造了 XX 价值"（太商业）→ 改"为国有资产保值增值贡献了力量"
- ❌ "我提出的方案"（太突出个人）→ 改"在充分调研基础上建议……被采纳"
- ❌ "我 hold 住了全场"（太江湖）→ 改"确保了工作的平稳有序推进"

## 三个强度档的措辞差异

| 档位 | 措辞风格 | 示例 |
|---|---|---|
| 🟢 保守 | 严谨、规范、政治话术多 | "在……的正确领导下，本人作为……，主要承担了……工作" |
| 🟡 标准 | 适度拔高、有数据、有担当 | "聚焦重点难点，主动担当作为，牵头完成了……，取得 X 成效" |
| 🔴 激进 | 强政治站位、敢下判断、敢用最高级 | "坚决扛起……政治责任，在关键时刻发挥了中流砥柱作用" |

## 完整示例片段

> **岗位职责**：综合管理岗
>
> **保守版**：
> 本人主要负责公文流转、会务组织、后勤保障等综合事务工作。一年来，共处理公文 X 件，组织会议 X 次，未发生重大差错。
>
> **标准版**：
> 本人聚焦"三服务"主责主业（服务决策、服务落实、服务基层），着力提升综合管理质效。**全年累计处理公文 X 件，组织重要会议 X 余次，实现公文流转"零差错"、会务保障"零失误"**。同时，主动服务基层一线，深入 X 个下属单位开展调研，形成调研报告 X 篇，为领导科学决策提供了有力支撑。
>
> **激进版**：
> 本人始终把"两个维护"作为最高政治原则和根本政治规矩，自觉站在服务公司高质量发展大局的高度谋划本职工作。**聚焦"参谋助手"核心定位，全年牵头组织重要会议 X 场次、处置紧急公文 X 件，实现了"零差错、零延误、零泄密"的硬指标**。特别是在 XX 重大专项工作中，主动请缨、连续作战 X 昼夜，得到主要领导的肯定性批示。**工作中注重以文辅政、以会聚力、以调研资政**，撰写的 X 篇调研报告转化为公司决策依据，真正做到了"参在点子上、谋在关键处"。
